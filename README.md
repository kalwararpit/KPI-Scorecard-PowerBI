KPI Scorecard in Power BI

This project demonstrates a KPI scorecard built using Power BI to monitor organizational performance across financial, operational, and customer metrics.

The dataset is sourced from an Excel file and prepared using Power Query, including data type validation and basic transformations. KPIs include actual values, target values, KPI category, and KPI direction (higher or lower is better).

DAX measures were created to calculate KPI variance, performance ratio, and overall KPI status. Based on these calculations, each KPI is classified as On Track, At Risk, or Underperforming.

Conditional formatting was applied to the KPI Status column to visually highlight performance levels using color-coded indicators:
- Green: On Track
- Yellow: At Risk
- Red: Underperforming

The scorecard enables quick identification of underperforming KPIs and supports data-driven decision making.
